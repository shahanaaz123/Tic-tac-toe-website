# 🎮 Neon Tic Tac Toe

A modern Tic Tac Toe game built with HTML, CSS and JavaScript.

## Features

- Neon Cyberpunk UI
- Glassmorphism Design
- Animated Gradient Background
- Score Tracking
- Restart Game
- Reset Scores
- Winner Highlight Animation
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Run Locally

1. Download project files
2. Open folder
3. Double-click index.html

or

Use VS Code + Live Server
