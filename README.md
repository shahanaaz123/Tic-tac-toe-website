# 🎮 Tic Tac Toe

A modern and responsive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- Modern Glassmorphism UI
- Responsive Design
- Score Tracking
- Restart Game
- Reset Scoreboard
- Winning Cell Highlight
- Smooth Animations
- Mobile Friendly

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
tic-tac-toe/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download the project.
2. Open the project folder.
3. Double-click `index.html`.

Or use VS Code:

1. Open folder in VS Code.
2. Install Live Server extension.
3. Right click `index.html`.
4. Select "Open with Live Server".

## Gameplay

- Player X starts first.
- Players alternate turns.
- First player to align 3 symbols wins.
- If all cells are filled and no winner exists, the game ends in a draw.
